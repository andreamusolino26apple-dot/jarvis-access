Se Jarvis non risponde dalla chat:
Il server deve girare dal tuo terminale (non da un ambiente sandboxato). Sul Mac, apri Terminale nella cartella di Jarvis e lancia:
./Avvia\ Jarvis\ Remoto.command
Questo avvia server + tunnel insieme e la chat funziona.

Il link apre l'interfaccia completa di Jarvis: chat, voce, autonomia, servizi esterni.
Nota: l'URL del tunnel cambia a ogni riavvio del Mac. Aggiorna questa pagina dal repo se il link non funziona.

⚠️ Sicurezza Questo URL è pubblico: chiunque abbia il link può raggiungere Jarvis. Non condividere il link e chiudi il tunnel quando non lo usi. Le azioni che modificano il sistema richiedono comunque conferma.
